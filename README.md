# World Trade Marketplace — v0.0.1

A responsive, static front-end prototype for a business-to-business marketplace focused first on agricultural products.

## Run it
Open `index.html` in a modern browser. No installation or build step is required.

## Included
- Responsive landing page
- Sample agricultural product cards
- Search and filters for category and country
- Demo-only inquiry actions
- Clear notice that sample listings are not verified

## Important limitations
This is a visual prototype only. It does not yet include accounts, a database, real supplier inquiries, business verification, moderation tools, payments, or trade guarantees. Sample listings are illustrative and must not be treated as real offers.

## Suggested next milestones
1. Ask a few real buyers and suppliers to test the concept.
2. Design business registration and profile fields.
3. Add a database and secure authentication/access rules.
4. Add listing moderation, reporting, rate limits, and safe image uploads.
5. Review privacy, advertising, and cross-border trade requirements before launch.
